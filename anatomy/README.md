# Methodology anatomy

Two versions of the same figure:

- `membership-procedure-galaxy.html`: drawn as an astronomical survey (current).
- `membership-procedure-anatomy.html`: drawn as a manual telephone exchange (first version).

Each is an interactive figure of the membership-and-boundary procedure in the RESLA manuscript (v0.12), with the same content layer.

- **Parts**: 20 numbered parts. Each one maps to one methodological element, with the values the article gives and their section references.
- **Pipeline**: steps through the order of work, from archive to output.
- **N05 / N06**: step through the membership decisions on one row.

Every number in the figure comes from the manuscript. Items the article does not report are listed in the caption notes, not drawn.

The file is an Artifact page body. The publishing service adds the HTML skeleton, so the file has no `<!doctype>`, `<html>` or `<body>` tags. Browsers still render it when it is opened directly.
